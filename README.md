# Development of software modules

## Это репозиторий по дисциплине Разработка программных модулей

Этот курс учит основам промышленной backend-разработки на языке Python. В целом он дает базу для того, чтобы создавать серверные приложения с нуля: от настройки рабочего окружения и работы с системой контроля версий (Git) до написания кода, покрытия его тестами и подготовки проекта к развертыванию. Курс ориентирован на практическое освоение полного цикла разработки программных модулей.

### Здесь будут храниться:

 - my homeworks - папка с выполненными домашними заданиями
 - theory from lessons - теоретические материалы, выданные учителем
